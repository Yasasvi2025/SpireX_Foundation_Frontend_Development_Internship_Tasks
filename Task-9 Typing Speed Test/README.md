# Task-9:⌨️Typing Speed Test

A modern, responsive **Typing Speed Test web application** built with **HTML, CSS, and JavaScript**.

Test your typing speed, improve accuracy, track your performance, and practice with different difficulty levels in a clean and interactive interface.

---

## ✨ Features

* ⚡ Real-time **WPM (Words Per Minute)** calculation
* 🎯 Real-time **typing accuracy** calculation
* ⏱️ Countdown timer
* 📝 Character-by-character typing feedback
* 📊 Typing progress indicator
* 🎚️ Easy, Medium, and Hard difficulty levels
* 🌙 Light / Dark theme toggle
* 💾 Saves recent typing test progress using `localStorage`
* 🏆 Performance evaluation
* 🎉 Confetti animation for successful results
* 📋 Detailed result summary
* 🔄 Restart and Reset options
* 📱 Responsive design for desktop, tablet, and mobile
* ⌨️ Keyboard shortcuts
* 🎨 Modern purple-themed UI with glassmorphism styling

---

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling, animations, responsive design, and themes
* **JavaScript (ES6+)** — Application logic and interactions
* **Font Awesome** — Icons
* **Google Fonts (Poppins)** — Typography
* **LocalStorage** — Saving typing progress

## 🎮 How to Use

1. Select a difficulty level:

   * **Easy** — 60 seconds
   * **Medium** — 60 seconds
   * **Hard** — 45 seconds
2. Click **Start Test** or simply start typing.
3. Type the displayed paragraph.
4. The application calculates:

   * WPM
   * Accuracy
   * Correct characters
   * Incorrect characters
   * Progress
   * Time taken
5. Complete the paragraph or wait until the timer finishes.
6. Click **View Result** to see the detailed result.
7. Use **Restart** or **Try Again** to practice again.

## 📊 Performance Levels

The application evaluates performance based on WPM and accuracy.

| Performance          | Requirement               |
| -------------------- | ------------------------- |
| 🏆 Excellent         | 60+ WPM and 95%+ accuracy |
| ⭐ Great             | 45+ WPM and 90%+ accuracy |
| 👍 Good              | 30+ WPM and 80%+ accuracy |
| 💪 Keep Practicing   | 70%+ accuracy             |
| 📚 Needs Improvement | Below the above levels    |

## 🌙 Theme Support

---

## 💾 Progress Tracking

The application stores the latest **20 typing tests** locally in the browser.

Stored information includes:

* Date
* Difficulty
* WPM
* Accuracy
* Correct characters
* Incorrect characters
* Time taken

No external database or server is required.
