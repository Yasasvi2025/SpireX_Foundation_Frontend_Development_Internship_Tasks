# 🚀 Task 1: Personal Portfolio Card | SpireX Foundation

A clean, modern, and responsive single-page personal portfolio website built using HTML5, CSS3, and JavaScript as part of the **SpireX Foundation Frontend Development Internship**. The portfolio showcases technical skills, featured projects, certifications, internship experience, and contact information through an interactive and user-friendly interface.

---

## ✨ Features

* **🌓 Dynamic Theme Switching:** Seamless dark mode and light mode toggle with state retention.
* **📱 Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewports using CSS Flexbox and Grid.
* **⌨️ Dynamic Typing Effect:** Animated role presentation in the hero section.
* **📊 Animated Skill Bars:** Smooth scroll-triggered progress bars showing technical proficiency.
* **📂 Portfolio Showcase:** Highlighted internships, featured projects, certifications, and educational background.
* **✉️ Contact Integration:** Built-in contact form layout with quick-access social and direct contact links.
* **🔗 Professional Links:** Quick access to GitHub, LinkedIn, and Email.
* **🔝 Back to Top Button:** Interactive smooth-scrolling shortcut for enhanced navigation.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Layout:** CSS Flexbox, CSS Grid
- **Styling:** CSS Variables, Responsive Design, Media Queries
- **Icons:** Font Awesome 6
- **Typography:** Google Fonts (Plus Jakarta Sans)
