## 🧮 BMI Formula

The application uses the standard BMI formula:

```text
BMI = Weight (kg) / Height² (m²)
```

For example:

```text
Weight = 65 kg
Height = 1.70 m

BMI = 65 / (1.70 × 1.70)

BMI = 22.5
```

## 📊 BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | 🔵 Underweight |
| 18.5 – 24.9 | 🟢 Normal Weight |
| 25 – 29.9 | 🟡 Overweight |
| 30 – 34.9 | 🟠 Obesity |
| 35+ | 🔴 Extremely Obese |

## 💡 How It Works

1. Enter or select your height.
2. Select the height unit.
3. Enter or select your weight.
4. Select the weight unit.
5. Click **Calculate BMI**.
6. The application calculates and displays your BMI.
7. The BMI category is displayed.
8. The BMI scale pointer indicates the result.
9. Use **View Details** to see BMI analysis.
10. Use **About BMI** to learn more about BMI.
