# 🎟️Task-12:Event Registration System

A modern and responsive **Event Registration System** built using **HTML, CSS, and JavaScript**. The application allows users to explore upcoming events, view event information, register for events, and manage their registrations through an interactive interface.

---

## 🚀 Project Overview

The **Event Registration System** provides a simple and user-friendly platform for discovering and registering for events.

Users can:

* 🎫 Browse upcoming events
* 📅 View event dates
* 📍 View event locations
* 👥 Check available registration information
* 📝 Register for an event
* 📋 View their registrations
* 🔎 View registration details
* 🌙 Switch between Light and Dark themes
* 📱 Use the application on desktop, tablet, and mobile devices

---

## ✨ Features

### 🏠 Home Section

* Modern navigation bar
* Event Registration System branding
* Navigation links
* Profile button
* Hero section with event introduction
* Browse Events button

### 🎪 Upcoming Events

The project includes three sample events:

1. **Music Night 2025**

   * Live music and entertainment
   * City Auditorium, New York

2. **Tech Conference**

   * Technology and innovation event
   * Tech Hub, San Francisco

3. **Food Festival**

   * Food, culture, and cuisine
   * Food Plaza, Los Angeles

Each event includes:

* Event image
* Event name
* Description
* Date
* Location
* Registration count
* Register Now button

### 📝 Registration Form

Users can provide:

* Full Name
* Email Address
* Phone Number
* Select Event

The form allows users to register for available events.

### 📋 My Registrations

The application displays registered events with:

* Event Name
* Date
* Location
* Registration Status
* View Details action

### 🌙 Light / Dark Theme

The application supports both:

* ☀️ Light Theme
* 🌙 Dark Theme

Users can switch between themes using the theme toggle button.

### 📱 Responsive Design

The interface is designed to work across:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

---

* **CSS3** – Styling, responsive design, animations, and themes
