# 📱 Task-3: Responsive Navbar

A modern and fully responsive navigation bar built using **HTML5, CSS3, and JavaScript**. The project features a desktop navigation menu, a mobile sidebar with a profile section, an animated hamburger menu, dark/light mode toggle, and smooth responsive behavior across different screen sizes.

---

## ✨ Features

- 📱 Fully Responsive Navigation Bar
- 🍔 Animated Hamburger Menu
- 📂 Mobile Sidebar Navigation
- 👤 Profile Section in Mobile Menu
- 🌙 Light / Dark Mode Toggle
- 🔗 Social Media Links
- ⚡ Smooth Animations & Transitions
- 💻 Desktop, Tablet & Mobile Friendly

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Font Awesome 6**
- **Google Fonts (Plus Jakarta Sans)**
