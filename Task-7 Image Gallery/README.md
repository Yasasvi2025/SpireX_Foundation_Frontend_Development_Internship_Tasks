# Task-7:🖼️ Image Gallery

A modern and responsive **Image Gallery Web Application** built using HTML, CSS, and JavaScript.

The gallery provides a beautiful glassmorphism-style interface with image categories, favorites, carousel navigation, image preview, detail view, and light/dark theme support.

---

## ✨ Features

- 🖼️ Beautiful Image Gallery UI
- 🌱 Category-based image filtering
- 💜 Add/remove images from Favorites
- 🌙 Light and Dark Theme Toggle
- ⬅️➡️ Previous/Next Carousel Navigation
- 🔍 Full Image Preview Popup
- ↗️ Image Detail View Popup
- ⌨️ Keyboard Navigation
- 📱 Responsive Design
- ✨ Glassmorphism UI
- 🎨 Gradient Purple/Pink Theme
- 📊 Pagination Indicator
- 🖼️ 10 Gallery Images

## 🎯 How It Works

### Category Filter

Click a category button to display images belonging to that category.

### Favorites

Click the 🤍 button on an image to add it to Favorites.

Click it again to remove it from Favorites.

The **Favorites** category displays only images that have been marked as favorites.

### Image Preview

Click an image or the preview button to open the image in a larger popup.

### Detail View

Click the ↗️ icon to open the vertical image detail popup.

### Theme Toggle

Use the ☀️/🌙 toggle in the top-right corner to switch between light and dark themes.

### Carousel Navigation

Use the:

- `‹` Previous button
- `›` Next button

You can also use the keyboard:

- `←` Previous
- `→` Next
- `Esc` Close popup
