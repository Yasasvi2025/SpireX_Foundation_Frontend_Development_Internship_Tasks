# 🔐 Task-4:Login / Signup Form UI

A responsive **Login / Signup Form UI** built using **HTML, CSS, and JavaScript** featuring client-side validation, responsive design, Local Storage-based authentication simulation, and a modern glassmorphism interface. The application allows users to switch seamlessly between Login and Signup forms while demonstrating modern front-end development practices.

> **Task Objective:** Build a responsive Login/Signup interface using HTML, CSS, and JavaScript with client-side validation.

---

## 📌 Project Overview

This project demonstrates front-end form design and validation without using any backend technologies. Users can register, log in, and experience a modern responsive interface.

For demonstration purposes, user data is stored using the browser's **Local Storage**.

---

## ✨ Features

### 🔑 Login Form

- Login using **Username or Email**
- Password visibility toggle
- Remember Me option
- Forgot Password dialog
- Client-side validation
- SweetAlert2 notifications

### 📝 Signup Form

- Register a new account
- Full Name validation
- Email validation
- Username validation
- Strong Password validation
- Confirm Password validation
- Password Strength Meter
- Live password requirement checklist
- Terms & Conditions checkbox
- Avatar image upload with preview

### 🚀 Extra Features

- Responsive Glassmorphism UI
- Animated login card
- Dashboard after successful login
- Edit Profile
- Logout
- Delete Account
- Local Storage session management
- Mobile-friendly design
