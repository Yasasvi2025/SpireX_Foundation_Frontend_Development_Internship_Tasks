# 📄 Task-2: Simple Resume / CV Page

A clean, modern, and fully responsive Resume/CV webpage built using **HTML5, CSS3, and JavaScript**. The project features a Light/Dark Mode toggle, Print/PDF support, and a professional resume layout.

---

## 🌟 Features

- 📱 Fully Responsive Design
- 🌙 Light / Dark Mode Toggle
- 🖨️ Print & Save as PDF
- 🎨 Modern Resume Layout
- 📂 Professional Section Organization
- 🖼️ Profile Image Support
- 💾 Theme Preference Saved using Local Storage

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Font Awesome 6**
- **Google Fonts (Plus Jakarta Sans)**

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Yasasvi2025/SpireX_Foundation_Frontend_Development_Internship_Tasks.git
cd SpireX_Foundation_Frontend_Development_Internship_Tasks
```

### 2. Open the Project

Navigate to:

```text
Task-2 Simple Resume Page
```

Open the **index.html** file using one of these methods:

- Double-click **index.html**
- Open with **Live Server** in Visual Studio Code

### For Windows (Optional)

```cmd
cd "Task-2 Simple Resume Page"
start index.html
```

---

## 🖥️ Usage

- 🌙 Click **Dark Mode / Light Mode** to switch themes.
- 🖨️ Click **Print / Save as PDF** to print or export your resume as a PDF.
- 📱 View the resume on desktop, tablet, or mobile devices.
