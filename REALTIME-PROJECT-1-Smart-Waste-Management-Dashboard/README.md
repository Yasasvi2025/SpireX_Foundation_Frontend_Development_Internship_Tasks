# 🎮 Mini Project-1: Rock Paper Scissors Game

An interactive **Rock Paper Scissors Game** built using **HTML5, CSS3, and JavaScript**. The game allows users to play against the computer with real-time score tracking, match history, statistics, dark/light theme switching, keyboard shortcuts, sound effects, animations, and Local Storage support.

> **Task Objective:** Build a simple interactive game using HTML, CSS, and JavaScript where users play against the computer, with dynamic gameplay, score tracking, and instant result updates.

## 🎮 How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects its move.
3. The winner is determined instantly.
4. Scores update automatically.
5. The first player to reach **5 points** wins the match.
6. Click **New Match** to start a fresh game.
7. Click **Reset Score** to clear scores, statistics, and history.
